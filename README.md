# Always Drop Loot — NeoForge 26.2

NeoForge port for the Minecraft `26.2.x` series, built against Minecraft `26.2` and NeoForge `26.2.0.59`. One runtime JAR covers the whole declared series.

Build with Java 25 using `.\gradlew.bat build`; the artifact is written to `build/libs`. See the [main README](../../README.md) for installation, configuration, and the full compatibility matrix.
